# 🚀 OpenClaw 模型快速部署指南


欢迎使用 OpenClaw。通过本教程，您只需执行一行命令，即可利用 **Cooper-API** 极速完成模型集成。

![image.png](https://api.apifox.com/api/v1/projects/8059553/resources/650520/image-preview)

---

### 📝 准备工作
在开始之前，请确认您的设备已满足以下条件：
*   ✅ **已安装 OpenClaw**：核心程序已就绪。
*   🔑 **持有 Cooper-API Key**：确保您有一个可用的 API 密钥。

---

### 📥 部署步骤

| 步骤 | 操作说明 | 备注 |
| :--- | :--- | :--- |
| **01. 复制指令** | 复制下方【核心指令】框中的代码 | 自动化部署脚本 |
| **02. 开启终端** | **Windows:** 打开 **Git Bash** <br> **macOS:** 打开 **终端 (Terminal)** | 找不到可在开始菜单搜索 |
| **03. 执行脚本** | 在终端窗口中粘贴命令，按下 **Enter** | 脚本将自动准备环境 |
| **04. 模型导入** | 根据屏幕中文提示，输入 API Key 即可 | 按照引导完成最后一步 |

---

### 💻 核心指令

请复制并执行以下代码：
```bash
curl -fsSL https://files.cooper-api.com/script/openclaw-go.sh | bash
```

---


> ⚠️ **注意事项**
> *   **粘贴技巧**：Windows Git Bash 可以使用**鼠标右键**菜单`Paste`来粘贴。
> *   **网络环境**：请确保您的网络能够正常访问脚本下载地址。
> *   **安全建议**：请勿将您的 API Key 泄露给他人。
